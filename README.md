# BounceMyWindow
A Windows specific app that bounces your terminal window!
> [!NOTE]
> This doesn't work super well with the windows terminal
> I would recommend using the native console host 

## How to build
#### 1. Ensure you have the .NET SDK intalled
#### 2. Clone this repository
```
git clone https://github.com/yousif51811/FlarialReskin.git
```
#### 3. Publish the app.
```
dotnet publish -c Release
```
